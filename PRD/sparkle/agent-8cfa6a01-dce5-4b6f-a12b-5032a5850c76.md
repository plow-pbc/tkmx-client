### Summary of changes since last update

Addressed all three probes from the automated review on PR #94. Both blocking
security probes were about this repository being **public**: `.beads/config.yaml`
is the file `bd config set github.token` writes secrets into, and `bd dolt push`
would publish the whole beads database under `refs/dolt/data` on `origin`. Fixed
by untracking the config and replacing the push instructions with an explicit
prohibition. The medium probe (four duplicated copies of the same beads manual)
is fixed by collapsing to one canonical surface.

### Detail of changes made

- **Probe 1 (blocking, security)** — `git rm --cached .beads/config.yaml` and added
  `config.yaml` to `.beads/.gitignore`. The file stays on disk so `bd` keeps working;
  it is simply no longer tracked. Corrected the trailing NOTE in `.beads/.gitignore`
  that asserted config.yaml is tracked by default. `.beads/metadata.json` stays
  TRACKED — `project_id` / `dolt_database` are shared identity needed for sync.
- **Probe 2 (blocking, security)** — removed every instruction to run `bd dolt push`
  against this remote. `AGENTS.md` now states plainly that `origin` is public, that
  `bd dolt push`/`pull` must not target it, and that cross-machine sync needs an
  approved private Dolt remote configured out of band. Deleted `.beads/README.md`
  entirely: it was upstream marketing boilerplate whose only project-specific content
  was the `bd dolt push` quick-reference this probe flags, and it also carried an
  unpinned `curl … /main/scripts/install.sh | bash` installer.
- **Probe 3 (medium, simplification)** — `AGENTS.md` went 127 → 40 lines and
  `CLAUDE.md` 77 → 14. The repo declares `profile:minimal`, which says instruction
  files should be pointers to `bd prime`; there were four near-identical manuals
  (AGENTS.md top section, the BEADS INTEGRATION block, the BEADS CODEX SETUP block,
  and CLAUDE.md). Now one pointer each, with `.agents/skills/beads/SKILL.md` as the
  single canonical detailed surface. Kept the non-interactive-shell guidance, which
  is real project ops content rather than duplicated beads docs, and added the actual
  build/test commands to CLAUDE.md.
- Net effect on the PR: roughly 230 tracked lines removed, consistent with the repo's
  stated preference for cutting LOC over adding it.
